# Career-Copilot (全能职位匹配与智能投递智能体)

> **定位**：连接“个人经历主库”与“企业招聘/导师招生需求”的动态对齐、自适应简历定制与自动化代发系统。

## 项目架构与愿景

- 🎯 **双模驱动**：支持【企业校招/社招精准投递】与【学术界高校申博套磁】双模式
- 🧠 **需求对齐**：智能解析目标 JD / 导师学术画像，提取核心痛点与关键词
- 📝 **动态组装**：从个人经历主库中动态提取高匹配项目，自适应编译单页高命中率简历 PDF 与个性化自荐信
- 📬 **一键代发**：深度集成 `agently-mail` 自动化邮件协议，支持带附件批量/精准投递与状态回执监听
- 📈 **成长雷达**：输出个人背景与目标职位的 Gap 分析，指导技能提升与项目迭代

## 目录结构

```
Career-Copilot/
├── docs/                # 产品需求文档 (PRD)、架构设计、开发计划
├── src/                 # 核心 Python 源码 (引擎、加载器、编译器、代发器)
├── templates/           # 简历与套磁信模板 (Typst / HTML)
├── data/                # 个人经历主库 (Master Profile Vault) 与投递数据库
└── apply.py             # 统一 CLI 与 Agent 入口
```
