## 一、 产品背景与核心价值

### 1.1 痛点分析
1. **千篇一律 vs 精准匹配**：传统盲投回复率极低，而手动针对每个岗位/导师修改简历和自荐信极其耗费精力（每天最多 5~10 家）。
2. **格式与排版痛点**：Word 排版容易乱码、Markdown 转 PDF 不够精美，缺少自动化的高颜值单页 PDF 渲染工具。
3. **成长与需求脱节**：投递后不知道自己到底差在哪里，无法将外界真实招聘需求反哺给日常的科研、竞赛和技能提升。

### 1.2 产品使命
构建一个由 Agent 驱动的 **“个人首席职业/申博参谋长”**：
- **学术界**：一键调研博导论文 ➔ 生成定制学术 CV 与套磁信 ➔ 自动发信与追踪；
- **工业界**：一键解析招聘 JD ➔ 动态组装针对性单页简历 ➔ 邮件直投与打招呼；
- **个人成长**：输出技能差距雷达，形成以市场/学术需求为导向的长期成长闭环。

---

## 二、 用户交互与运行模式

* **主要交互方式**：**纯 Agent 对话驱动**（在 Antigravity / Claude Code 中直接对话：“*帮我分析这个岗位 JD 并生成简历*” 或 “*调研张教授并准备套磁信*”）。
* **自动化程度**：**人在回路（Human-in-the-loop）半自动确认**。
  - Agent 解析需求 ➔ 组装定制简历 ➔ 终端/对话内展示自荐信与简历预览 ➔ 用户确认 `[Y/N]` ➔ 调起 `agently-mail` 发送。
