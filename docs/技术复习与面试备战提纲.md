## 二、 简历四大核心技术栈深度复盘（必考原理与公式）

### 2.1 大模型量化、微调与推理优化

#### 1. 显存计算与 INT4 压缩推导（被问概率 90%）
* **Qwen2-7B FP16 显存**：$7.6 \times 10^9 \text{ 参数} \times 2 \text{ Bytes} \approx \mathbf{15.2\text{ GB}}$（纯权重）。
* **INT4 量化后**：每个权重占 $0.5 \text{ Bytes}$，权重显存压缩为 $7.6 \times 0.5 \approx \mathbf{3.8\text{ GB}}$。
* **实际运行时总显存**：权重 (3.8G) + KV Cache (1.0G) + 激活值与 CUDA Context (1.0G) $\approx \mathbf{5.8\text{ GB}}$。
* **显存降幅**：$\frac{14 - 5.8}{14} \approx \mathbf{58.5\%}$。

#### 2. 量化方案对比：GPTQ vs AWQ vs NF4
* **GPTQ**：二阶泰勒展开，利用逆 Hessian 矩阵按列逐块更新未量化权重，误差补偿极快；
* **AWQ**：只保护 1% 的关键激活通道（Salient Weights），对非显著通道做 INT4，保持逻辑推理能力不崩塌；
* **NF4 (NormalFloat 4)**：假设预训练权重服从正态分布，构建等信息量量化区间，搭配**双重量化（Double Quantization）**进一步节省显存。

#### 3. QLoRA 核心公式与 Paged Optimizers
* **公式**：$W = \text{dequantize}(W_{\text{NF4}}) + \frac{\alpha}{r} (A \cdot B)$（$A \in \mathbb{R}^{d \times r}, B \in \mathbb{R}^{r \times k}$，$r=16, \alpha=32$）；
* **Paged Optimizers**：利用操作系统页表机制，在显存突发尖峰时将优化器状态换入 CPU 内存，彻底防止 OOM。

#### 4. vLLM 推理加速：PagedAttention
* 传统静态分配导致 60%+ 内存碎片；PagedAttention 将 KV Cache 切分成固定大小 Block（如 16 tokens/块），通过逻辑块到物理块的动态映射表，显存利用率达 96%+。

---

### 2.2 边缘端计算与模型部署（TensorRT + Jetson Orin Nano）

#### 1. TensorRT 优化机制
* **算子融合 (Layer Fusion)**：将 `Conv + BN + SiLU/ReLU` 融合成单一 Kernel，消除中间 Feature Map 写入显存再读取的带宽浪费；
* **INT8 PTQ 校准**：利用 KL 散度（相对熵）在 Calibration Dataset 上最小化激活值量化信息损失。

#### 2. Orin Nano 达到 45+ FPS 的实操调优手段
1. **统一内存 (Unified Memory) 零拷贝**：Orin Nano CPU/GPU 共享物理 LPDDR5，使用 Unified Memory 避免主机到设备的 PCIe 复制开销；
2. **CUDA Stream 异步三级流水线**：
   * `Stream 1`：当前帧预处理（Letterbox、RGB 归一化、NCHW 转换）；
   * `Stream 2`：上一帧 TensorRT 异步推理；
   * `Stream 3`：上上帧 NMS 后处理与坐标还原。三者完全重叠并发。

---

### 2.3 计算机视觉与工业落地（YOLOv11 / P2 / 单目测距 / ReID）

#### 1. YOLOv11 结构升级
* **Backbone**：引入 C3k2 结构与 C2PSA（自注意力空间机制），提升复杂背景下的特征捕获能力；
* **Head**：Anchor-Free 解耦头（Decoupled Head），分类与回归分支独立计算损失，消除梯度冲突。

#### 2. 为什么加入 P2 高分辨率特征层？
* 传统 YOLO 最小检测头 P3 下采样 8 倍，对于原图中 $< 16 \times 16$ 的小目标（如井盖、航拍违建），特征图仅剩 $1 \sim 2$ 像素，特征丢失严重；
* **P2 层（4 倍下采样，$160 \times 160$ 特征图）**：保留了极为丰富的浅层几何轮廓与纹理，小目标检测召回率显著提升。

#### 3. 单目测距数学推导与抗颠簸（中电科 50 所）
* **几何成像公式**：$Z = \frac{f \cdot H}{h}$（$f$ 为内参标定焦距，$H$ 为目标物理高度，$h$ 为检测框像素高度）；
* **车载颠簸消歧**：引入**一阶低通滤波与卡尔曼时域平滑**，结合 ReID 特征锁定同一目标 Track ID，消除车辆行进抖动引起的距离跳变，将 5~50 米误差控制在 5% 以内。

### 2.4 Multi-Agent、RAG 与 AI-Native 研发范式

* **4 层 Multi-Agent**：日志解析 Agent $\to$ 向量检索 Agent $\to$ 因果推理 Agent $\to$ 报告排版 Agent；

* **Action（行动）**：
  1. 我主导采用 GPTQ/AWQ 对 Qwen2-7B 进行 INT4 量化与 QLoRA 微调，显存由 14GB 压缩到 5.8GB；

## 四、 面试高频“连环炮”速查与标准应答策略

| 面试官常问问题 | 你的标准得分话术 |
| :--- | :--- |
| **Q1: 为什么量化到 INT4 不会导致大模型逻辑崩溃？** | “因为大模型参数具有显著的稀疏性与分布规律。我们采用 AWQ/GPTQ 算法，通过保留关键激活通道并在二阶泰勒展开下逐层补偿误差，使得困惑度（Perplexity）增量控制在极小范围内，在下游具体任务上准确率损失小于 1.5%。” |
| **Q2: 遇到模型在端侧推理显存溢出（OOM），你怎么排查和解决？** | “按四步排查：① 检查 Batch Size 与输入最大 Token 限制；② 启用 PagedAttention 或 TensorRT 静态显存分配；③ 开启算子融合并降低中间 Feature Map 暂存；④ 开启 QLoRA Paged Optimizers 将状态换入 CPU 内存。” |
| **Q3: 目标检测中小目标漏检严重，你一般从哪些维度改进？** | “① **特征分辨率**：增加浅层 P2 特征层；② **多尺度融合**：引入自适应特征融合 AMSFF，避免简单 Add 造成的特征稀释；③ **数据增强**：采用 Copy-Paste、Mosaic 提高小目标出现频次；④ **损失函数**：引入针对小目标的 Wise-IoU 或 Focaler-IoU。” |

## 五、 面试收尾：高情商反问面试官（展示 FDE 深度）

当面试官问：“你还有什么想问我们的吗？”时，推荐以下 3 个高水平问题：

1. **问业务与落地痛点（展现 FDE 意识）**：
   > “请问目前团队在将大模型/视觉算法交付给客户或下沉到端侧时，遇到的最大工程痛点通常是算力显存限制、延迟要求，还是现场数据的长尾 Corner Case？”
2. **问工具链与架构（展现技术前瞻性）**：
   > “了解到贵团队在做 [某业务]，请问目前团队内部在算法交付阶段，主要采用 TensorRT / vLLM 还是自研的推理中间件？未来是否有向 Multi-Agent 协作流演进的规划？”
3. **问团队期待（展现快速上手意愿）**：
   > “如果我有幸加入团队，在前三个月里，团队希望我重点攻克哪一部分业务或模块的落地工作？”
